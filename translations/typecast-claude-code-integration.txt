# 클로드 코드용 타입캐스트 음성 연동

Stop 훅을 이용해 클로드 코드의 응답을 선택한 타입캐스트 AI 캐릭터 음성으로 자동으로 읽어줍니다.

## 파일 구성

- `scripts/typecast_client.py` — 공용 API 클라이언트(인증, /voices, /text-to-speech)
- `scripts/typecast_list_voices.py` — 사용 가능한 보이스(캐릭터) 목록 조회
- `scripts/typecast_speak.py` — 텍스트를 음성으로 변환해 재생 (단독 실행 가능)
- `.claude/hooks/typecast_stop_hook.py` — 클로드의 마지막 응답을 읽어주는 Stop 훅
- `.claude/settings.json` — Stop 훅 등록 (타임아웃 30초)
- `credentials/typecast_api_key.txt` — API 키 (git에서 제외됨, 커밋되지 않음)
- `credentials/typecast_voice_id.txt` — 선택한 보이스의 voice_id (git에서 제외됨)

## 최초 설정

1. https://typecast.ai/developers/api/ 에서 무료로 API 키를 발급받아
   `credentials/typecast_api_key.txt` 파일에 한 줄로 저장합니다 (따옴표 없이).
   또는 `TYPECAST_API_KEY` 환경변수로 설정해도 됩니다.
2. 사용 가능한 보이스 목록을 조회합니다:
   ```
   python scripts/typecast_list_voices.py
   ```
3. 원하는 보이스를 선택해 해당 voice_id를 `credentials/typecast_voice_id.txt`에 저장합니다.
4. 직접 테스트해봅니다:
   ```
   python scripts/typecast_speak.py "안녕하세요, 테스트입니다."
   ```
5. 클로드 코드에서 `/hooks`를 실행하거나 세션을 재시작해 새로 등록한
   Stop 훅이 적용되도록 합니다.

## 동작 방식

클로드 코드가 응답할 때마다 Stop 훅이 stdin으로 `last_assistant_message`를
전달받아 마크다운/코드블록/URL을 제거하고 500자로 잘라낸 뒤, 저장된
voice_id로 `typecast_speak.speak()`를 호출합니다. 재생은 윈도우 내장
`winsound` 모듈을 사용하므로 추가 설치가 필요 없습니다. 오류(키 누락,
네트워크 오류 등)는 `credentials/typecast_hook_error.log`에 기록되며
클로드 코드 동작을 막지 않습니다 — 훅은 항상 exit 0으로 종료됩니다.

## 비활성화 방법

`.claude/settings.json`에서 `hooks.Stop` 섹션을 제거하거나,
`credentials/typecast_voice_id.txt` 파일을 삭제하면 됩니다
(이 경우 훅은 실패하고 로그만 남깁니다).
