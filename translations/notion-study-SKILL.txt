# 노션 학습 등록

사용자가 언급한 학습 목표(강의, 시험/자격증 준비 항목, 어학 공부 계획 등)를 노션의 "학습" 데이터베이스에 새 페이지로 등록합니다. Notion API 도구(`notion-fetch`, `notion-create-pages`, `notion-search`)만 사용하며, 브라우저 자동화나 Playwright는 절대 사용하지 않습니다.

## 알려진 위치 정보

- 상위 페이지: "노션 db 연동 실습" (`https://app.notion.com/p/3cac1740333f80a1a657f705112bb28e`)
- 데이터베이스: "학습" (`https://app.notion.com/p/d493740677784deb9a14fdf9f9546f3b`)
- 데이터 소스(스키마 조회/쿼리용): `collection://6f22d7c7-a820-4cd3-b04c-ce065418cefa`

이 값들은 참고용 기본값이며 보장되는 값이 아닙니다. **매번 등록하기 전에 위 데이터베이스 URL로 `notion-fetch`를 호출해 최신 스키마를 확인하세요** — 진행상태/난이도/분야 옵션 목록이 바뀌었을 수 있고, 워크스페이스가 다르면 ID가 완전히 다릅니다. 알려진 ID로 `notion-fetch`가 실패하면 `notion-search`로 "학습"을 검색해 현재 URL을 다시 찾으세요.

## 속성 스키마 (2026-08-31 기준)

| 속성 | 타입 | 설정 방법 |
|---|---|---|
| 제목 | title | 문자열. 페이지 제목이며 필수입니다. |
| 진행상태 | status | `"시작 전"`, `"진행 중"`, `"완료"` 중 하나. 생략 시 기본값은 `"시작 전"`입니다 |
| 난이도 | select | `"상"`, `"중"`, `"하"` 중 하나 |
| 분야 | select | `"개발"`, `"어학"`, `"자격증"`, `"기타"` 중 하나 |
| 목표일 | date | 아래 "목표일 설정" 참고 |
| 자료 링크 | url | URL 문자열 하나 (강의 페이지, 영상, 아티클 등) |
| 출처 | text | 일반 문자열 — 자료/강의의 출처(플랫폼, 책, 강사 등) |
| 등록보고서 제목 | text | 일반 문자열. 사용자가 단순 학습 목표가 아니라 이미 작성한 학습 *보고서/정리글*을 등록하는 경우에만 설정하세요 — 아래 참고 |
| 완료작업 | relation | 완료작업 데이터베이스와 연결하는 용도. 신규 학습 항목 등록 시에는 사용하지 않습니다 |

### 목표일 설정

`notion-create-pages`는 단일 `목표일` 키가 아니라 확장된 컬럼명을 사용합니다:

- `"date:목표일:start"`: ISO-8601 날짜 또는 날짜시간 문자열 (예: `"2026-10-31"`)
- `"date:목표일:is_datetime"`: 특정 시간이 주어졌다면 `1`, 날짜만 있다면 `0` 또는 생략
- `"date:목표일:end"`: 기간이 있는 값일 때만 설정하고, 단일 날짜라면 생략하세요

사용자가 "다음달 말까지", "3주 후"처럼 상대적인 날짜를 말하면, 이 형식으로 변환하기 전에 오늘 날짜를 기준으로 절대 날짜로 환산하세요. 사용자가 목표일을 전혀 언급하지 않았다면 임의로 만들어내지 말고 설정하지 않은 채로 두세요 — 기한 없는 학습 목표도 괜찮습니다.

### 분야와 난이도 추론

사용자가 분야나 난이도를 명시적으로 말하면 그대로 사용하세요. 그렇지 않다면:
- `분야`는 대부분 주제에서 확실하게 추론할 수 있습니다(예: "토익", "일본어" → `"어학"`; "정보처리기사", "AWS 자격증" → `"자격증"`; "React", "파이썬" → `"개발"`). 나머지 세 개에 진짜로 맞지 않을 때만 `"기타"`로 설정하세요.
- `난이도`는 개인적인 판단이 필요한 값이므로, 사용자가 직접 말하지 않는 한 설정하지 않은 채로 두세요.

### 등록보고서 제목에 대해

이 필드는 `제목`과 다릅니다: 학습 목표 자체가 아니라 이 항목에 연결된 학습 *보고서/정리글*의 제목을 담는 필드입니다(예: 챕터를 끝내고 정리 노트를 작성한 뒤). 단순히 새 학습 목표를 등록할 때는 비워두고, 사용자가 이미 작성한 보고서를 명시적으로 기록하려는 경우에만 채우세요.

## 등록 절차

1. "학습" 데이터베이스에 `notion-fetch`를 호출해 현재 데이터 소스 URL과 진행상태/난이도/분야 옵션 목록을 확인합니다.
2. 사용자 메시지에서 다음을 추출합니다: 제목(필수), 목표일(있다면), 분야(주제에서 명확하면 추론), 난이도(명시했다면), 자료 링크(있다면), 출처(언급했다면).
3. `parent`를 `{"type": "data_source_id", "data_source_id": "<위에서 확인한 데이터 소스 ID>"}`로 지정해 `notion-create-pages`를 호출합니다.
4. 생성된 페이지 URL을 사용자에게 알리고, 설정된 내용(제목/분야/목표일/난이도)을 간단히 요약해줍니다.
5. 사용자가 이후에 항목의 진행상태, 난이도, 목표일 수정을 요청하면 `notion-search` 또는 `notion-query-data-sources`로 해당 항목을 찾은 뒤 `notion-update-page`로 반영하세요.

## 예시

**입력**: "정보처리기사 필기 준비 시작했어, 다음달 말까지가 목표야. 노션 학습에 등록해줘"

**처리**:
- 제목: "정보처리기사 필기 준비"
- 진행상태: 설정하지 않음(기본값 "시작 전")
- 분야: "자격증" ("정보처리기사"에서 추론)
- 목표일: "다음달 말"을 절대 날짜로 환산. `date:목표일:start` = 해당 날짜, `date:목표일:is_datetime` = 0
- 난이도: 설정하지 않음(언급되지 않음)

**출력**: 생성된 노션 페이지 URL과 함께 "정보처리기사 필기 준비를 학습 DB에 등록했습니다 — 분야 '자격증', 목표일 10월 말." 같은 확인 메시지
