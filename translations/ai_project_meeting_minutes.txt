회의록: AI 프로젝트 진행 상황 점검

- 프로젝트: 스마트 어시스턴트 AI 플랫폼 (코드네임: "춘식이")
- 일시: 2026-08-31 (월요일)
- 시간: 10:00 - 11:15 (한국 표준시)
- 장소: 회의실 B / 구글 미트 (하이브리드)
- 참석자: 김민준(PM), 이지은(AI/ML 리드), 박상훈(백엔드 리드), 최예린(프론트엔드 리드), 정현우(QA 리드), 한소연(데이터 엔지니어)
- 불참: 없음
- 작성자: 김민준

1. 안건
1) 지난 스프린트 이후 진행 상황 리뷰
2) 모델 학습 및 평가 현황
3) 백엔드/API 연동 현황
4) 프론트엔드 UI 진행 상황
5) QA 및 테스트 계획
6) 리스크 및 블로커
7) 액션 아이템 및 마감 기한

2. 진행 상황 요약
- 3분기 로드맵 대비 전체 프로젝트 진행률은 65%.
- 핵심 추천 모델(v2) 학습이 완료되었으며 v1 대비 정확도가 4.2% 개선되었으나, 지연 시간이 180ms 증가하여 출시 전 최적화가 필요하다는 데 의견을 모음.
- 백엔드 팀은 신규 `/v2/recommendations` API 엔드포인트 구현을 완료했으며, 부하 테스트가 남아 있음.
- 프론트엔드 팀은 대시보드 리디자인 목업을 완료하고 새 채팅 인터페이스 구현을 시작함.
- QA에서 지난 테스트 사이클 기준 12건의 미해결 버그를 발견함(치명적 3건, 주요 5건, 경미 4건).

3. 주요 논의 내용
- 모델 지연 시간: 이지은이 지연 시간 단축을 위해 INT8 양자화 추론 방식 전환을 제안. 다음 리뷰 전까지 프로토타입 제작에 합의.
- 데이터 파이프라인: 한소연이 상위 분석 소스의 스키마 불일치로 야간 ETL 작업이 간헐적으로 실패한다고 보고. 현재 수정 진행 중.
- API 요청 제한: 박상훈이 외부 파트너 연동 시 요청 제한(rate limit) 처리에 대한 우려를 제기함. 플랫폼 팀과 협의 예정.
- UI 접근성: 최예린이 새 채팅 인터페이스 출시 전 접근성(WCAG 2.1 AA) 검토가 필요하다고 언급.
- 치명적 버그: 정현우가 치명적 버그 3건 중 2건이 스테이징 배포를 막고 있어 우선 해결이 필요하다고 강조.
