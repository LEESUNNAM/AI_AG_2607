# Reference Images — 냉방병 (Air-Conditioning Syndrome) Card News Layouts

Collected for the [air-conditioning syndrome design concept](../../design-concept/air-conditioning-syndrome/en/air_conditioning_syndrome_design_concept.md). Two search tracks were used, each covering the 3 layout types the concept's 5-frame structure relies on: **cover/hook**, **info/list**, **CTA/closing**.

- **Track A — "디자인 레퍼런스" (broader/English-language design reference)**: healthcare/wellness infographic and app design, sourced via Behance search.
- **Track B — "카드뉴스" (Korean card news reference)**: real Korean card news projects (government and editorial), sourced via Behance search.

All images are Behance search-result thumbnails (404×316px) — sufficient for mood/layout comparison, but low-res for direct reuse; see license note below.
